Procedimiento

  1. Conecta el reloj LILYGO mediante un cable USB de datos.
  2. Pulsa Conectar ESP32-S3.
  3. Selecciona el puerto correspondiente al reloj.
  4. Pulsa Instalar firmware.
  5. El Web Flasher descargará automáticamente la última versión publicada.
  6. No desconectes el reloj hasta que aparezca el mensaje de instalación completada.
